# Repository Guidelines

## Project Structure & Module Organization
- `src/lib.rs` is the Rust/WASM entry point and exports the app surface to JavaScript.
- `www/` contains the web client: `index.html`, CSS, and the main Three.js scene logic in `www/scene.js`.
- `www/shared/` and `www/features/` host UI feature modules and shared client utilities.
- `www/tests/` contains custom JavaScript test suites and a runner.
- `assets/` holds static art (sprites, images) used by the UI.
- `pkg/` and `dist/` are build outputs (generated by wasm-pack and `./build.sh`).

## Build, Test, and Development Commands
- `wasm-pack build --target web --dev` builds the WASM bundle for local development.
- `wasm-pack build --target web --release` creates an optimized production bundle.
- `./build.sh` performs a full production build and assembles `dist/`.
- `cd www && python -m http.server 8080` serves the site locally.
- `bun test www/tests/run-all.js` (or `node www/tests/run-all.js`) runs the JS test suite.

## Coding Style & Naming Conventions
- Rust follows the standard `rustfmt` style (4-space indentation, trailing commas).
- JavaScript in `www/` uses 4-space indentation and descriptive, lowerCamelCase names.
- File naming is kebab-case in `www/` (e.g., `stack-state.js`, `bottom-sheet.css`).
- Prefer clear, explicit identifiers for UI elements and constants (see `www/scene.js`).

## Testing Guidelines
- Tests are plain Node/Bun scripts in `www/tests/` with a minimal custom harness.
- Name test files `*.test.js`; keep one suite per feature module.
- Run `www/tests/run-all.js` before UI changes; add coverage for new UI state logic.

## Commit & Pull Request Guidelines
- Commit messages follow Conventional Commits: `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`.
- Keep commits scoped to one change; include issue/PR references when available.
- PRs should include: a short summary, test command(s) run, and screenshots for UI changes.

## Agent Notes
- `CLAUDE.md` documents architecture details, UI layout conventions, and preferred tooling (Bun).
